## 二、后台配置

### ⬜ 1. 小程序类目（**先确认这一条，它可能一票否决**）

后台 → 设置 → 基本设置 → 服务类目。

解梦内容在微信属于敏感区，个人主体可选类目本身也受限。**在做任何其他事之前，
先确认当前类目是什么**，如果类目不覆盖当前的内容形态，代码改再多也过不了。

真正需要联网核查的是最新版《微信小程序运营规范》里命理/占卜类的口径——
`docs/MARKET_FEASIBILITY_REVIEW_2026-07-16.md` 里的合规结论当时**没有联网核验过**，
不要直接拿它当依据。

### ⬜ 2. 用户隐私保护指引

后台 → 设置 → 服务内容声明 → 用户隐私保护指引。

代码里 `__usePrivacyCheck__` 已经打开，**后台这份指引没配置的话，隐私接口
（麦克风、相册）会被微信直接拦掉**，语音输入和存图都会失效。这两件事必须同时到位。

按下面勾选和填写：

| 收集的信息 | 用途说明（填进「你的小程序将收集…用于…」） |
|---|---|
| 麦克风 | 用于语音口述梦境。音频会发送至腾讯云语音识别服务转成文字，不做留存。 |
| 相册（写入） | 用于将生成的梦境卡片图片保存到你的手机相册。 |
| 你主动提供的信息 | 你输入的梦境内容，以及可选填写的昵称、出生日期/时间/地点。 |
| 设备标识 | 微信 openid，用于区分账号、隔离每个人的梦境记录。 |

**第三方服务（必须如实声明，这是审核最常挑的一项）**：

- 梦境文本发送至第三方 AI 服务（DeepSeek）用于生成解读
- 语音音频发送至腾讯云语音识别服务用于转写文字
- 画面提示词发送至第三方图像生成服务用于生成梦境卡片插画
- 数据存储于微信云开发（CloudBase），按 openid 隔离

**用户权利**：小程序内提供删除单条梦境记录的入口（删除会级联清除关联的生活线索、
生成的图片资源、派生的画像快照，并撤销已生成的分享卡）。

### ⬜ 3. 云函数环境变量（新增两个）

后台 CloudBase 控制台 → 云函数 → 环境变量：

```text
interpretDream:
  ADMIN_OPENIDS=<你自己的 openid>      # 新增：不配置的话 smokeTest 对所有人关闭

generateDreamImage:
  IMAGE_DAILY_LIMIT=6                  # 可选：不配置则默认 6
```

其余变量（DEEPSEEK_API_KEY、OPENAI_IMAGE_* 等）沿用
`docs/MINI_PROGRAM_RELEASE_CHECKLIST.md` 里的配置。

## 三、部署（改动过的云函数必须重新上传）

微信开发者工具 → cloudfunctions 目录 → 右键「上传并部署：云端安装依赖」：

- `interpretDream` — 内容安全 + smokeTest 权限校验
- `saveDream` — 内容安全
- `createShareCard` — 内容安全（strict）
- `generateDreamImage` — 每日生图配额

**三个函数新增了 `config.json` 声明 `security.msgSecCheck` 的 openapi 权限。
没有这个声明，云调用会直接失败**——届时私密链路会静默降级成放行（fail-open），
分享则会被全部挡住（fail-closed）。这是验证部署是否成功的最快判据。

## 四、真机验收（提审前必做）

在 `docs/MINI_PROGRAM_RELEASE_CHECKLIST.md` 已有的 16 条之外，本轮新增：

1. 首次触发录音时弹出隐私弹窗；点「同意并继续」后录音正常启动。
2. 点「暂不同意」后弹窗关闭，**打字记梦、读解读、翻梦册全部照常可用**——
   拒绝只该影响语音和存图。
3. 弹窗里「查看完整指引」能打开微信托管的那份指引（后台配置生效后才有）。
4. 记一条正常的梦，解读照常产出——确认内容安全没有误伤正常内容。
5. 同一天生成第 7 张图时收到配额提示，且文案里说明梦已存下、明天可继续。
6. 用非管理员账号在诊断页点 `AI SMOKE TEST`，应返回 `not_admin` 而不是真的发起调用。
7. 分享一张梦卡，确认能正常生成——如果被挡住，检查 `createShareCard` 的
   `config.json` 权限声明是否随函数一起部署上去了。
